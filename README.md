## 1 Общее описание системы

Общее описание системы, для которой разрабатывается ПО из репозитория.

### Назначение

Программное обеспечение представляет собой специализированный HTTP-фильтр (Web Application Firewall), работающий по принципу обратного прокси-сервера (Reverse Proxy). Система предназначена для защиты веб-приложений от распространённых киберугроз, таких как SQL-инъекции, XSS-атаки и аномальные HTTP-запросы.

### Описание системы

Система состоит из нескольких функциональных модулей, развёрнутых в изолированных контейнерах:
1. Nginx: Принимает весь входящий трафик и распределяет его между панелью управления и анализатором трафика.
2. Engine: Сервер фильтрации на языке Python, выполняющий сигнатурный (на базе регулярных выражений) и эвристический анализ трафика.
3. Web: Панель администратора и личный кабинет пользователя для настройки правил защиты и просмотра статистики.

> Документ: `docs/SYSTEM_SPECS`

## 3 Алгоритм настройки и запуска

### Структура директорий репозитория

1. `accounts/` — логика профилей пользователей и настроек сайтов.
2. `avatars/` — хранилище загруженных изображений профилей.
3. `engine/` — исходный код анализатора трафика.
4. `nginx/` — конфигурация Nginx.
5. `waf_project/` — системные настройки Django-проекта.
6. `docker-compose.yml` — описание всей инфраструктуры проекта.
7. `Dockerfile.web` / `Dockerfile.engine` — инструкции по сборке образов.

### Входные точки в программу

Доступ и регистрация:
- `http://localhost:8000/login/` — страница аутентификации пользователей.
- `http://localhost:8000/register/` — страница регистрации новых владельцев сайтов.
- `http://localhost:8000/2fa/setup/` — настройка двухфакторной аутентификации.

Личный кабинет пользователя (Dashboard):
- `http://localhost:8000/dashboard/` — основная панель мониторинга защищаемых ресурсов.
- `http://localhost:8000/dashboard/logs/download/` — точка выгрузки логов посещений и атак.

Панель управления администратора (Admin Panel):
- `http://localhost:8000/panel/` — центральный интерфейс управления системой (доступен только для ролей с правами администратора).
- `http://localhost:8000/panel/rules/` — управление сигнатурами и правилами фильтрации WAF.
- `http://localhost:8000/panel/users/` — управление учётными записями и правами доступа.
- `http://localhost:8000/admin/` — встроенная административная панель Django для низкоуровневого управления БД.

### Алгоритмы запуска ПО для отладки

1. Клонировать репозиторий и перейти в корень проекта.
2. Запуск контейнеров: `docker-compose up -d`.
3. Создание администратора: `docker-compose exec -it <имяконтейнера>-web-1 python manage.py createsuperuser`.
4. Настройка OAuth: зайти в `localhost/admin/` -> Social Applications -> добавить приложение GitHub, указав Client ID и Secret Key.
